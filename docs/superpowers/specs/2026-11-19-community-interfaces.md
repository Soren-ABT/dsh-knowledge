# 社区需求与现有接口

社区提出了两种使用场景。一种是用本地模型持续更新科研 Wiki，另一种是在不同工作区使用专用知识库。[本地模型与目录同步反馈](https://github.com/Soren-ABT/dsh-knowledge/issues/57#issuecomment-6620806365) · [工作区与 Markdown 反馈](https://github.com/Soren-ABT/dsh-knowledge/issues/57#issuecomment-6834597554)

## 已接入的接口

| 接入点 | 当前调用方 | 约定 |
| --- | --- | --- |
| `KnowledgeService.resolveInvocationScope(requestedBaseIds?)` | 自动检索、系统提示、搜索工具、库名展示 | 每次调用读取当前选择。返回全部库的 ID 和名称以识别被点名的库，并单独返回可用范围。请求范围与已启用范围取交集。显式空数组和已全部失效的选择均匹配零个库。 |
| `KnowledgeService.listBases()` | 管理面板、需要统计的工具 | 一次遍历文档元数据生成计数与来源摘要。仅需要名称和范围的模型调用走上面的轻量接口。 |
| `fetchUrlDocument(url, signal)` | URL 导入、手动刷新、定时刷新 | 统一执行逐跳校验、下载限时、解码后字节计数及格式识别。输出标题和文本，供原有分块、嵌入和引用链使用。 |
| `commitRebuiltDocument` | 文件重建、URL 刷新 | 候选原文与分块通过已有的暂存与提交日志发布。SQLite 已发布但元数据确认失败时，恢复流程完成确认。 |

旧库的 `urlCheckedAt` 缺失时，调度器沿用原有更新时间。新建或重命名 URL 文档时可记录 `urlTitleOverride`，以便后续抓取保留用户标题。两个字段都是可选项，现有文档可直接打开。

## 后续功能的接入条件

| 社区方向 | 现成的接入点 | 后续实现需要解决的问题 |
| --- | --- | --- |
| 工作区隔离、按标签过滤、仅工具检索 | 将可信会话 cwd 对应的库 ID 传给范围解析器，按同一范围选择重排器 | 在提示组装、自动注入、按 ID 读写的工具上统一应用策略。将自动注入开关与显式工具权限分别求值。当前接口提供按调用过滤，cwd 规则仍待实现。 |
| 更换嵌入模型后仅重算向量 | 已提交原文、现有分块、嵌入模型标识、暂存与提交日志 | 按库记录切换进度，处理中断与重试。检索应能辨认当前向量空间，每篇文档的原子提交不足以保证整库模型切换。目录重扫的文件哈希继续只表示源文件是否改变。 |
| Markdown 导出及批量导入 CLI | 目录与文档列表、分页读取、HTTP 导入与刷新 | 导出需约定文件名冲突、目录层级及来源信息的表示。批量导入需复用服务的去重与失败结果，支持部分成功后的重试。 |
| 减少工具 schema 开销 | DSH 工具注册、执行时的范围校验和删除确认 | 白名单需要影响模型可见的注册表，同时保留执行时校验。单入口工具和旧名称需要明确兼容期。 |
| 查看一次自动注入的依据 | 范围解析器给出候选库，搜索结果已有检索模式、耗时与重排状态 | 可在会话调试面板展示命中的库、跳过原因和最终送入模型的引用。仅开启调试时记录，查询正文和原文片段应由用户选择是否保留。 |
| 文件监听、独立嵌入服务 | 目录重扫已与删除串行，同一来源的并发重扫会合并。嵌入已有 OpenAI 兼容与 Ollama 适配器 | 文件事件可触发现有重扫，监听器由来源和插件生命周期管理。独立服务可沿用已有远程适配器，自动批量策略需在目标 CPU/WSL 环境验证内存峰值。 |

## 性能验证

在 Windows、Node 24.16.0 上，按反馈中的三个库构造了 1,739 篇短文档和 15,055 个分块。对照版本为 `5e13845`。测试使用 SQLite 分块库和进程内元数据表，计时范围仅覆盖表中的操作。

| 操作 | 调用次数 | 优化前中位数 | 优化后中位数 | 每次操作的读取变化 |
| --- | ---: | ---: | ---: | --- |
| 自动检索识别用户显式点名的停用库 | 200 | 0.479 ms | 0.024 ms | 文档目录从 6 次遍历降至 0 次 |
| 管理面板列出三个库的统计 | 120 | 0.223 ms | 0.100 ms | 文档目录从 3 次遍历降至 1 次 |
| 核对原文快照引用 | 20 | 15.765 ms | 0.125 ms | 从逐篇读取 1,739 次暂存记录改为一次读取暂存记录头 |
