# dsh-knowledge v0.3.7 — Local reranking hardening, UI chunk previews, CI lifecycle

This release hardens the local cross-encoder runtime by moving it into a
dedicated forked process, adds full-chunk previews to the document viewer,
and tightens the packed-install lifecycle supervision.

## Local reranking (cross-encoder)

- The local cross-encoder now runs in a dedicated `fork`ed process
  (`rerank-process.mjs`), never imported by the host. Each start is a fresh
  process space, structurally eliminating same-process native-binding reload
  issues; the IPC protocol is versioned and the runner supports model
  switching, batched inference, and disposal.
- `smoke-local-rerank.mjs` runs a discriminating self-test on the real
  `Xenova/bge-reranker-base` model (scores must order correctly), covering
  initial startup and process recovery. CI gains a manually triggered
  `local-rerank-smoke` job (Ubuntu, model cache, Node 22.19/24) — the first
  Linux real-model verification path.

## UI

- Document viewer supports expanding complete chunk previews instead of only
  the retrieved snippet.

## CI & release tooling

- Packed-install lifecycle supervision (install → boot → uninstall) with
  partial-uninstall timeout classification; relaxed native integration
  timeouts; release preflight (`release:check`) unchanged.

## Quality

- Full unit suite, retrieval benchmark (Hit@1 ≥ 95%), and release preflight
  all pass before publication.
