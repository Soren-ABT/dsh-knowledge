# dsh-knowledge v0.6.0-beta.1

本次预发布面向用网页、项目手册和团队 Wiki 搭建知识库的用户。可以直接导入 Markdown 原文链接，在多个已启用的库中限定搜索范围，并在刷新资料时继续使用上一份成功的索引。

## 来源与检索

- 从管理面板、HTTP API 或 `knowledge_import_url` 导入 HTML 网页和 UTF-8 Markdown 原文。单次抓取上限为 8 MiB、30 秒。手动和定时刷新可复用同一次请求，保留文档 ID、目录和自定义标题。刷新失败后仍可检索上次成功的内容。
- `knowledge_search` 支持 `baseIds`。它与当前启用范围取交集，空数组返回空结果。现有的 `baseId` 和省略范围的调用方式继续可用。自动检索的去重记录按服务和会话保存。
- 汇总知识库时只遍历一次文档元数据。启动时只检查已配置的本地重排模型，卸载时等待 URL 任务和本地子进程结束。检索、重排、上下文拼接与工具注册已有独立模块。

## 本地模型和升级

- Windows 上本地向量模型下载完成后，临时文件锁会触发有界重试。重试期间可以取消，连续失败会保留已下载的暂存文件。PaddleOCR 和 Transformers.js 共用 ONNX Runtime 1.30.0。
- 从 0.5.4 升级可直接打开已有知识库。新增的 URL 检查时间和自定义标题标记是可选字段，升级无需全库重建。备份时一起保留 storage-domain 元数据、SQLite、`knowledge-raw` 和 `knowledge-artifacts`。
- 发布候选包使用 npm 的 `beta` 渠道。npm 发布后可运行 `dsh plugin --profile <profile> add dsh-knowledge@0.6.0-beta.1`。本地打包验证可使用同一条命令安装 `./dsh-knowledge-0.6.0-beta.1.tgz`。

## Compatibility

The Windows and Ubuntu native jobs install the tarball into a fresh DSH `0.2.2-rc.5` profile, boot DSH, call the knowledge API, and check plugin removal. Source builds use the matching upstream `dsh-v0.2.2-rc.5` commit. The 15 model tools retain their public names and schemas.
