# dsh-knowledge v0.5.4 — 分块质量、后台维护与桌面布局修复

发布日期：2026-11-15

0.5.4 汇总 0.5.3 之后的已合并修复，改善纯标记片段和短文本的分块处理，将启动产物清理移至后台，清理删除知识库后的文档残留，并修复桌面标题栏和共享侧边栏入口的布局。

## 分块与空索引（#67 / #68）

- 过滤已识别的独立标记片段，避免分隔线、空的环境边界等内容单独进入索引。
- 智能分块在同一标题节和大小预算内合并较短的块，保留标题边界、字面代码和正文。自定义分隔符模式继续遵守显式边界。
- 明确完成但没有可索引内容的文档保持完成状态，启动时不再将其反复视为中断导入。
- 已有索引不会自动重写；需要应用新规则的旧文档可手动重建。

## 后台维护与删除清理（#70 / #73 / #74）

- 启动不再逐篇等待产物 GC。扫描延后至后台执行，最多使用四个 worker，插件卸载时取消。
- 删除旧产物前重新读取当前、暂存和可恢复任务的 revision，防止后台扫描与文档重建交错时使用过期的保护信息；未使用的 revision 继续保留七天。
- 删除知识库时同时删除其文档记录。启动恢复清理旧版本遗留的无主记录及对应的暂存、待确认 generation，保留仍属于有效知识库的正常恢复路径。
- 无主记录清理使用宿主逐条写入接口；历史残留较多时，首次修复仍可能占用启动时间。后台 GC 修复不代表其他存储打开和恢复工作无需耗时。

## 桌面标题栏与共享侧边栏（#69 / #72 / #75）

- 面板在操作栏上方绘制独立的可拖动标题栏区域，避免标题、开关和关闭按钮覆盖原生窗口控件。
- 保留 Window Controls Overlay 几何信息；宿主可通过根元素的 `--host-titlebar-inset` 或 `--dsh-windows-titlebar-height` 调整预留高度。Electron/Tauri 的 macOS 和 Windows 回退值分别为 38px 和 40px，全屏时移除留白。
- 展开侧边栏时，共享页脚入口按按钮数量分配等宽列；折叠时纵向排列图标。知识库入口不再使用超宽和负边距，过长文字保留可访问名称并省略显示。

## 宿主依赖（#71）

- 将构建产物运行时使用的 `zod` 声明为宿主提供的 `^4.4.3` peer dependency，并在打包检查中校验该声明。
- 源码开发继续使用仓库固定的 DSH 兼容提交，保持宿主与插件的 Zod 类型一致。该声明本身不解决任意新版宿主中的源码类型差异。

## 升级与验证

- 从 0.5.3 升级无需数据库格式迁移、模型重新下载或强制全库重建。
- 备份应一起保留 storage-domain 元数据、SQLite、`knowledge-raw` 和使用中的 `knowledge-artifacts`，以恢复资料及其处理证据。
- 发布前执行 `npm run release:check -- --expected-version 0.5.4 --tag v0.5.4`，覆盖版本与构建策略、生产依赖审计、类型检查、测试、检索基准、构建、临时打包校验和四类 worker 协议检查；该命令不发布 npm 包。
- 启动回归覆盖 7,200 篇文档及未完成的清理任务；界面验证使用实际 React 组件和共存插件的旧样式。报告中的 Windows 冷启动库、原生 macOS 控件和窗口拖动仍需在原宿主中复测；真实模型及托管 MinerU 推理沿用独立验收流程。

## English summary

- **Chunking:** filter recognized markup-only fragments, merge short smart chunks within their heading section and size budget, preserve literal code and authored content, and retain completed empty indexes across restarts. Rebuild existing documents to apply the updated rules.
- **Startup and deletion:** run artifact GC after initialization with at most four workers, refresh live/staged/job revision pins before deletion, cancel on unload, and retain unused revisions for seven days. Collect document metadata when removing a base and clean up historical base-less records, including staged and pending generations.
- **Desktop UI:** reserve a separate draggable titlebar band with host overrides, Electron/Tauri fallbacks and fullscreen updates. Share footer width between actions in wide sidebars and stack rail icons when collapsed.
- **Host contract:** declare `zod: ^4.4.3` as a host-provided peer and verify the declaration during package checks. Source development remains aligned with the pinned DSH compatibility anchor.
- **Upgrade:** no database-format migration, model redownload or mandatory library-wide rebuild is required from 0.5.3. A large historical orphan cleanup can still take time. Keep metadata, SQLite, raw sources and active artifacts together when backing up.
- **Verification:** the non-publishing release preflight checks metadata, build policy, production auditing, types, tests, retrieval benchmarks, bundles, package contents and four worker protocols. The original Windows cold-start library and native macOS window behavior still require host-level confirmation; real-model and managed MinerU inference remain separate checks.
